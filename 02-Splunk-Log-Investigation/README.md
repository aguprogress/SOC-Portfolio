# Splunk Log Investigation

## Objective
To investigate security logs using Splunk SIEM platform.

## Tools Used
- Splunk
- Windows Event Logs

## Analysis
- Performed log searches using Splunk queries
- Investigated login and process events
- Filtered security-related logs for anomalies

## Findings
- Identified patterns in failed login attempts
- Correlated login success and failure events
- Observed system activity after authentication

## Conclusion
Demonstrates SIEM-based log analysis and SOC monitoring workflow.
